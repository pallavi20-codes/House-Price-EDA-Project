## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of house prices to understand the factors affecting property values.

It includes data analysis, statistical summaries, data visualizations, and an interactive dashboard.

## Objectives
- Understand the housing dataset.
- Identify missing values and analyze data distributions.
- Study relationships between different housing features.
- Visualize factors affecting house prices.
- Build an interactive dashboard for data exploration.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
- Google Colab
